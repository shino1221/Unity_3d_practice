# ABYSS RESCUE

Unity **6000.3.24f1** 프로젝트입니다. `Assets/Scenes/MinePrototype.unity`를 열어 실행합니다.

조작, 수정 위치, 팀원별 연결 API와 남은 기획 차이는 [플레이어·스태미나 통합 안내](Documentation/MinePrototype/README.md)를 참고하세요.
